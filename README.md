# MindTrail SG

MindTrail SG is a React Native + FastAPI prototype for cognitive-risk case-finding in older adults and caregivers. The MVP uses two mini-tasks:

1. **Picture Story / Voice Task** — captures speech-language features.
2. **Clock / Pattern Draw Task** — captures drawing/process features.

The product is **not a dementia diagnosis tool**. It produces domain-level risk signals and a GP/caregiver-ready report for follow-up.

## MVP goal

Build an end-to-end demo:

```text
Welcome → Consent → Profile → Caregiver checklist → Voice task → Clock/drawing task → Results → GP-ready report
```

## Tech stack

| Layer | Stack |
|---|---|
| Mobile app | React Native / Expo / TypeScript |
| Backend | Python / FastAPI |
| ML + scoring | Python feature extraction + rule-based scoring first |
| Dataset | DementiaBank / ADReSS for speech-language modelling |
| Database | SQLite later for MVP |
| Report | HTML/PDF generated by backend |

## Local development commands

### Mobile

```bash
cd apps/mobile
npm install
npm run start
```

Then open the Expo Go app on a device, run on a simulator, or press `w` in the
Expo terminal for web preview.

### Backend

```bash
cd services/api
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Verify the API:

```bash
curl http://localhost:8000/health
```

Expected response:

```json
{"status":"ok"}
```

## Current scaffold

The initial scaffold includes:

- `apps/mobile/`: minimal Expo React Native app with TypeScript.
- `services/api/`: minimal FastAPI app with `GET /health`.
- `ml/speech/`: placeholder for speech-language feature extraction.
- `ml/drawing/`: placeholder for drawing feature extraction.

The voice task, clock/pattern drawing task, scoring endpoints, report generation,
and SQLite persistence are intentionally not implemented yet.

## MVP non-goals

Do not build these in the first iteration:

- Diagnosis claims.
- Authentication.
- HealthHub/Singpass integration.
- Full brain-training library.
- MRI model.
- Daily clinical scoring.
- Production-grade clinical validation.

## Safe product language

Use:

> MindTrail SG supports cognitive-risk case-finding and GP follow-up. It does not diagnose dementia.

Avoid:

> We diagnose dementia.

> We detect Alzheimer’s.

> Our app is clinically accurate.

# Research References

This folder stores research-only references and exploratory assets for MindTrail SG.

These files are not production app/backend code. Production drawing flow is defined in `ml/drawing/` and `docs/SCORING_SPEC.md`.

## Contents

- `cdt-api-network/`: preserved clock-drawing image-model exploration assets.
- `trebledawson-alzheimers-clock-drawing/`: optional external reference repo, if added.

## Safety note

Clock-drawing outputs must be framed as non-diagnostic cognitive-risk signals, not dementia or Alzheimer’s diagnosis. Dataset licenses and privacy status must be checked before keeping raw participant drawings in Git.
